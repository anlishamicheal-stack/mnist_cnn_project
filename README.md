# Handwritten Digit Recognizer (PyTorch, CNN)

A convolutional neural network (CNN) built from scratch in PyTorch to classify handwritten digits from the MNIST dataset.  
Achieves **99.1% test accuracy** with a reproducible training pipeline.

## 🚀 Features
- PyTorch implementation of CNN for MNIST
- End-to-end training and evaluation pipeline
- Modular code structure (`src/` folder)
- Easy reproducibility with `requirements.txt`
